# 设计与验证记录

视觉方向依据用户上传工作台参考与新生成的完整首页概念。概念文件由 image_gen 生成，已通过 view_image 查看。界面按用户实际流程实现为代码原生 UI，不将截图作为页面。

- 白色侧栏 + 浅灰绿色工作区；深绿为主要动作，琥珀色为待确认/待验证。
- 保留今天、团队、生意、获客、数据以及商品资料、渠道、我的；旧9人方案按新规格收敛为7人。
- 首屏为四步入驻、资料上传/文字建档、7人协作图、老板决策关口与市场来源。
- 上传上限按实际解析能力改为15MB，未保留概念中的50MB及PPT/图片支持。
- 客服由概念图误画的免费可用改为“待开通”；只有总管与文员免费。
- H3描述使用用户情报包的准确区域假设，而非概念生成图中泛化的市场判断。
- 无虚构客户与指标；未连接/未付费状态如实显示。
- 图标使用统一 Lucide 描边，非装饰性图片。
- 响应式断点涵盖桌面、平板与手机：移动端侧栏抽屉，团队横向人员栏，收件箱切为横向客户选择。

浏览器验证限制：当前工具清单未提供 Browser/IAB 或 cua_repl.js。Sites 技能在 managed-linux 下明确禁止这种情况自行启动替代预览/浏览器控制，因此没有运行 Playwright 或启动预览。构建、Worker资产请求和 D1/R2 全栈接口测试不等于浏览器渲染测试。本次未完成截图像素比较、原生视口验证、控制台与交互可视化验收，不能声称视觉10/10或浏览器验收通过。

上线后应在可用浏览器中验证：1536×1024首页、390×844手机、注册→上传→事实确认→8题方案→批准→订阅、私信→首回→自动报价→批准→买家确认→订单、退订/过期窗口/弱网发送不确定等状态。
