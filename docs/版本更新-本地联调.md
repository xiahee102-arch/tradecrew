# 本地联调版更新

本版针对localhost:8899用户反馈的“出海战略持续研究中”问题。

修复内容：

1. MiMo请求明确使用JSON结构化输出并关闭默认长思考，避免思考耗尽最终回答预算；截断或空输出不会被当作成功。
2. 策略生成限制篇幅、压缩上下文，保留来源编号和置信度校验。方案重试会切换到MiMo Flash，并记录原因，不伪造结果。
3. 浏览器通过有完整请求生命周期的工单执行接口推进任务，自动刷新结果。3分钟未完成的中断任务转为可重试失败，界面展示原因。
4. 缺少已确认事实时，在提交问卷时立即提示，不创建必然失败的空任务。
5. “我的”加入真实模型连接检查，可查看模型、耗时和实际token使用；不会返回Key。
6. 增加本机启动器、Windows/macOS脚本、隐藏输入Key、稳定的持久化存储路径和启动迁移。
7. 本地开发权限与真实付款分开；新工厂账单仍为空。
8. GitHub CI不需要密钥，自动构建和测试；源码包不含Key、数据库或原始客户数据。
